# Fitness

A multi-user strength training tracker built with Next.js, TypeScript, Prisma,
SQLite, and Biome.

## Development

```bash
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

The development server uses port `8783` by default.

Development seed credentials:

- Username: `admin`
- Password: `admin`

## Checks

```bash
npm run check
npm run build
prek run -a
```
